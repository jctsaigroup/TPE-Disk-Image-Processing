    Simulating Residual Stresses

    This page explains the residual-stress term used in Step 3 force inversion. The implementation is in StressSolve_residue_torch in src/force.py.

    Where it appears in code

    • src.force.StressSolve_residue_torch(...): builds total stress from contact forces plus residual stress, then maps stress to intensity.
    • src.force.synth_img_pytorch_residue(...): calls the stress solver with power=6 and fills a disk mask on a px x px grid.

    Contact-force stress term

    For each pixel inside a disk and each contact, the solver computes a contribution to:

    • sigmaxx
    • sigmayy
    • sigmaxy

    These come from vectorized contact geometry (f, alpha, beta) and are summed over contacts.

    Residual-stress model in the code

    After contact stress is computed, an axisymmetric residual field is added in polar form.

    Definitions used in StressSolve_residue_torch:

    • \(R = \sqrt{x^2 + y^2 + \varepsilon}\)
    • \(\Theta = \operatorname{atan2}(x, y)\)
    • \(p =\) power (currently fixed to \(6\) by synth_img_pytorch_residue)

    Residual coefficient:

    \[ K_{res} = -\frac{f_\sigma}{\pi\,p\,r_m^p}\,\arcsin(1) = -\frac{f_\sigma}{2\,p\,r_m^p} \]

    Residual radial and tangential stresses:

    \[ \sigma_r^{res} = K_{res}(r_m^p - R^p) \]
    \[ \sigma_t^{res} = K_{res}(r_m^p - (p+1)R^p) \]

    These are rotated into Cartesian components and added to contact stress:

    \[ \sigma_{xx}^{tot} = \sigma_{xx} + \sigma_r^{res}\cos^2\Theta + \sigma_t^{res}\sin^2\Theta \]
    \[ \sigma_{yy}^{tot} = \sigma_{yy} + \sigma_r^{res}\sin^2\Theta + \sigma_t^{res}\cos^2\Theta \]
    \[ \sigma_{xy}^{tot} = \sigma_{xy} + (\sigma_r^{res} - \sigma_t^{res})\sin\Theta\cos\Theta \]

    Stress-to-intensity mapping

    The code computes principal-stress difference magnitude:

    \[ \Delta\sigma = \sqrt{(\sigma_{xx}^{tot}-\sigma_{yy}^{tot})^2 + 4\sigma_{xy}^{tot\,2}} \]

    Then intensity:

    \[ I = \sin^2\left(\frac{\pi}{f_\sigma}\Delta\sigma\right) \]

    This is exactly what StressSolve_residue_torch returns (after nan_to_num safety cleanup).

    Practical meaning of parameters

    • fsigma: photoelastic calibration scale; changes fringe density/intensity response.
    • rm: disk radius in the solver coordinate system.
    • power: controls radial profile shape of residual stress; currently fixed at 6.
    • eps: tiny positive number for numerical stability in division and square roots.

    Why this helps fitting

    Without a residual term, the optimizer may force contact vectors to explain background/internal disk fringes that are not contact-induced. Adding this term lets the model account for baseline stress structure, reducing bias in fitted contact forces.
